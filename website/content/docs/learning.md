## 先阅读，再实践

课程页面保留原课件的目标、讲解、示例、练习、常见问题与下一步。左侧找到相邻课程，右侧快速跳到本课某个知识点。

有配套演示时，页面会显示互动入口。演示在独立页面打开，使用“返回课程”链接回到阅读页。

## 在 Claude Code 中带练

先按[快速开始](/docs/start/)安装并启动相应教学 Skill，然后点击课程页的“复制本课学习提示”，粘贴到教学对话中。

提示包含本课课号和标题，帮助教练定位原始课件。网站不会自动启动本机工具，也不自动同步教学进度；把你的练习结果带回教学会话，教练会继续讲解。

## 主线与补充课

第一次学习可以先关注主线课程。产品课程首页提供“只看主线课程”选项，方便浏览。

补充课用于深入某个主题。完整目录和前后导航保持课程地图的顺序，包括补充课；筛选目录不会改变课程编号。

## 把自己的项目带进来

将课件中的示例替换成你正在做的项目，说明目标、限制和已有材料。课程中用于启动其他 Skill 或 Agent 的实操命令，应在新的 Claude Code 会话中执行，然后回到教学会话继续。
