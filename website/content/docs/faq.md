## 必须安装才能看课吗？

不用。网页可以直接阅读，已有互动页面也可以打开。安装用于在 Claude Code 中获得教学入口、本地课件和带练流程。

## 安装 cc4pm 后，为什么某个参考命令不可用？

教学模块与完整参考实现的安装范围不同。查看[课件与参考工具](/docs/modules/)，确认该命令是否存在于当前项目配置中。

## 网站和终端课件是否分别维护？

课程正文来自同一批 Markdown 文件，目录来自课程地图。网站构建补充导航和链接，不另写课程正文。终端已经安装的副本不会因网站更新自动改变；需要更新本地安装后才能获得新内容。

## 需要 QMD 才能学习吗？

不需要。QMD 是终端教练可选的本地搜索增强。网站搜索使用静态索引，不需要读者安装 QMD。

## 为什么搜索中文时换一种说法就找不到？

本站中文搜索使用连续词句匹配。可以试试更短的词，例如“上下文”，或对应英文名称，例如 MCP、CLAUDE.md。欢迎通过 GitHub Issue 提交应当能找到的搜索词。

## 实操命令会中断教学吗？

启动其他 Skill 或 Agent 可能接管当前会话。按[实操须知](/docs/practice/)在新会话里练习，再回到教练会话。

## 律师课程可以直接作为实际案件处理流程吗？

它提供教学案例和方法示范。真实机构需要由专业团队替换成自己的 SOP、材料与复核标准。请先阅读[课程定位](/courses/lawyer/)。
